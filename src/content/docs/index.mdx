## The same parts, three places

Swiftide's traits are small enough that one value does several jobs. Each row is from a showcase you can run.

| One value | Does | And | In |
| --- | --- | --- | --- |
| an `OpenAI` client | drives the agent in each branch (`ChatCompletion`) | renders the architecture document (`SimplePrompt`) | workspace-architect [`graph.rs`](https://github.com/bosun-ai/swiftide/blob/{{swiftide_sha}}/examples/workspace-architect/src/graph.rs) |
| a `LocalExecutor` | runs the agent's git commands | answers the program's own git queries through the same `ToolExecutor` | release-notes-agent [`main.rs`](https://github.com/bosun-ai/swiftide/blob/{{swiftide_sha}}/examples/release-notes-agent/src/main.rs) |
| a `Qdrant` store | receives chunks with `then_store_with` | serves hybrid search with `then_retrieve` | docs-qa [`index.rs`](https://github.com/bosun-ai/swiftide/blob/{{swiftide_sha}}/examples/docs-qa/src/index.rs), [`query.rs`](https://github.com/bosun-ai/swiftide/blob/{{swiftide_sha}}/examples/docs-qa/src/query.rs) |
| a FastEmbed model | embeds chunks at index time | embeds the question at query time | ask-your-codebase [`embedding.rs`](https://github.com/bosun-ai/swiftide/blob/{{swiftide_sha}}/examples/ask-your-codebase/src/embedding.rs) |
| a plain `fn` | is a pipeline step (`then`) | is a task node (`register_node_fn`) or a tool (`#[tool]`) | ask-your-codebase [`index.rs`](https://github.com/bosun-ai/swiftide/blob/{{swiftide_sha}}/examples/ask-your-codebase/src/index.rs), workspace-architect [`graph.rs`](https://github.com/bosun-ai/swiftide/blob/{{swiftide_sha}}/examples/workspace-architect/src/graph.rs), release-notes-agent [`tools.rs`](https://github.com/bosun-ai/swiftide/blob/{{swiftide_sha}}/examples/release-notes-agent/src/tools.rs) |

Wrap a client or an embedder in `LanguageModelWithBackOff` for retries, or swap in `MockChatCompletion` in tests; the code that uses it does not change.

## What are you building?

| You want | Start with |
| --- | --- |
| An agent that reads, edits and runs code in a repository, with approval gates | [Agents](/agents/overview/) |
| Batch work with typed steps, parallel branches and a human in the loop | [Tasks](/tasks/overview/) |
| Answers about a codebase, with the files they came from | [Ask your codebase](/showcases/ask-your-codebase/) |
| Answers about documentation, with hybrid search, reranking and an evaluation score | [Docs Q&A](/showcases/docs-qa/) |
