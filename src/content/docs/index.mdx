## The same parts, three places

The same client, executor or store works in an agent, a task graph and a pipeline, so you wire a value once.

- **Values**\
  an `OpenAI` client, a `LocalExecutor`, a `Qdrant` store
- **Traits**\
  `ChatCompletion`, `SimplePrompt`, `ToolExecutor`, `Persist`, `Retrieve`
- **Runtimes**\
  [an agent](/agents/overview/), [a task graph](/tasks/overview/), [a pipeline](/indexing/overview/)

</Composition>
