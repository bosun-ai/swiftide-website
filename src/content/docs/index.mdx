## What are you building?

| You are building | Start with |
| --- | --- |
| A coding agent that reads, edits and runs code in a repository | [Agents](/agents/overview/) |
| Batch automation with typed steps, parallel branches and human approval | [Tasks](/tasks/overview/) |
| Answers over a codebase, from an index of its source | [Ask your codebase](/showcases/ask-your-codebase/) |
| Answers over documentation, with hybrid search and reranking | [Docs Q&A](/showcases/docs-qa/) |
